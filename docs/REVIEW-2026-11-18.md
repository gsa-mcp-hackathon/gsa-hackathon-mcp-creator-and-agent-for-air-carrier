## Fixed

1. **Code execution through generated eval files (high).** The purpose, user and
   questions were pasted raw into Python string literals in the generated
   `eval/phoenix` judges and agent. A purpose of
   `x"""+str(__import__("os").system("..."))+"""` produced a correctness judge
   that ran the command on import (reproduced). The same text broke
   `pyproject.toml`, `server.json` and `prompts/starters.py`, and could inject
   keys into `databricks.yml`. Fix: `utils.inert_text` applied wherever free
   text enters a generated literal; the bundle description is now quoted.
   Test: `tests/test_injection_safety.py` fuzzes every free-text field with 8
   payloads and asserts every file parses and the marker never appears outside
   a string constant (7 of 9 cases fail on the old code).
2. **Pasted schemas lost columns silently (high).** Only DESCRIBE lines, full
   DDL and CSV parsed. `name TYPE, name TYPE` (one line or wrapped), `name:
   type`, backticked names, markdown tables and `DECIMAL(18,2)` all lost
   columns or became string headers, so the taxi example lost its measures and
   got only a describe tool. Fix: a comma-list parser with a quote-aware
   top-level split. Tests: `test_models_and_profiling.py` (10 new cases).
3. **Unsafe table names accepted on the pasted-schema path (medium).** The
   identifier check ran only on live inspection, so `t; DROP TABLE x --`
   produced a server whose every call failed. It now runs on every UC table.
4. **`text_column` ignored; text tables got only describe (medium).** The
   review-table README example could not answer "Show reviews that mention
   wait times". The named column is now TEXT, and an unstructured UC table gets
   keyword search, lookup and counts, with a note pointing to AI Search for
   semantic search.
5. **`creator_write_project` wrote a design with no tools (low).** It now
   refuses, like `creator_generate_project`.
6. **One Hub MCP `get_table` path traversal (medium).** `get_table("../../x")`
   read any `.json` file the process could reach (reproduced). Reads are now
   confined to `app/data`. New suite `checks/test_mcp_server.py`.
7. **Live harness tests passed silently under pytest (low).** They returned
   `"skip"`, which pytest counts as a pass. They now call `pytest.skip`.
8. **Ops golden set had no runnable injection case.** Added q17, a direct
   injection (override text in the question; expected answer is q6's). q16,
   the planted-record case, stays TODO as its author intended.
9. README listed nine Creator tools; there are ten (`creator_deploy_server`).
10. **Generated projects failed their own lint with long names (medium).** A
    long package or tool name pushed two generated docstrings past 88
    characters, so 4 of 5 README examples failed `ruff check` on the first
    commit. Both lines now put the name on its own line. Test:
    `test_long_names_still_generate_a_lint_clean_project`.
11. **A moving-window question got the wrong tool (medium).** "Which awards
    expire in the next 90 days?" was answered by a ranking of awards by
    amount. No pattern filters dates relative to today, so the designer now
    reports it with the SQL to write by hand.

## Open, needs a decision or Databricks compute

* **Cost model is a placeholder.** `ops/harness/tools.run_cost_model_scenario`
  writes `"Cost model not yet implemented"` to `model_runs`. The cost-model
  specialist therefore cannot produce an EAC range. This is the largest
  functional gap for the CVN cost capture story.
* **Delegation eval evidence.** One run per configuration, no no-tool
  baseline, and only the `dev` set is recorded although the notebook says to
  quote `fresh`. Run `fresh` with 3 repeats per model, plus a no-tool run, and
  record latency next to tokens.
* **q16 indirect injection** needs a planted record in a source table.
* **Review sentiment.** "Which franchise has the most negative reviews" is
  mapped to a count of all reviews. Nothing records sentiment, so the honest
  answer is "not answerable without a sentiment column".
* **Lint configs.** `mcp-aircarrier-analyst`, `mcp-aircarrier-docs`, the probe
  and `ops-center` set no `select` list, so newer ruff versions report hundreds
  of style findings (none are defects; one unused local in
  `etl/build_extracts.py`). Pin `select = ["E", "F", "I"]` as the other
  projects do.

## Deploying these fixes

`tools/sync_from_workspace.py` copies workspace to repository. Running the sync
before applying the fixes to the workspace folders would revert them. Apply the
changed files to `~/mcp-server-creator`, `~/mcp-servers/mcp-aircarrier-ops` and
`~/the-one-hub/the-ops-center/.bundle/aircarrier/dev/files` first, redeploy
`mcp-a-creator`, then sync.
