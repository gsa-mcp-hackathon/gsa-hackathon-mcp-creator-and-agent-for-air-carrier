The seven capabilities

What each solves, for whom, and where it stands today

MCP A Creator

10 tools, 8 skills

Problem. Turning a dataset into a tool an agent can use takes a developer and weeks, and an improvised server is untested and different every time.

Profiles the table, designs one tool per question, reviews meaning as well as shape, and generates a tested project that deploys as the requester's own app after an approval bound to what was reviewed.

Beyond CVN-79
Every office with a Unity Catalog table and a question; GSA's stated aim of an internal library of MCP server prototypes.
Today
Built the ops server in this hub and, on an unrelated sales table, mcp-bakehouse-sales, rebuilt through its own tools in 0.38 s (7 tools, up from 4). 15 of 15 generated projects pass their own tests; output byte-identical across processes. Release 1.0.0rc2 with a changelog and SBOM, installable with uvx; every project records its spec, Creator version and file hashes, and mcp-a-creator-upgrade regenerates it without overwriting the owner's edits. Tested on FastMCP 3.4 and 4.2.

Docs server

11 tools

Problem. Budget justification books and SARs run to hundreds of pages, and analysts retype exhibits into spreadsheets.

Maps each book by exhibit and budget line, rebuilds tables with exact decimals, ties out every subtotal and total, and says whether a figure appears in an authoritative or only a secondary source. No model.

Beyond CVN-79
Budget analysts, cost estimators, congressional and GAO staff and auditors, on every appropriation's books and every program's SAR.
Today
34 PDFs and 7,804 pages loaded; 7,743 of 7,746 tie-out checks pass over all 34 PDFs, the 3 left within rounding. Known answers at p50 1.18 s since the cache fix (12.6 s before). The reader has no CVN-79 logic.

Analyst server

12 tools

Problem. The slowest work in audit remediation is researching one record that is missing data elements: no contract, no line of accounting, no hull.

Profiles what is missing, chases clues across FPDS, File C, sub-awards, the knowledge graph and the documents, weighs the evidence, and returns ranked cases with citations and a collection request for each missing element.

Beyond CVN-79
Component reconciliation teams, DFAS, FIAR teams and auditors, on unsupported transactions and Universe of Transactions gaps.
Today
Reads the two CVN-79 prime contracts; attribution raised from 42.2% to 75.8% of the hull in one pass.

Ops server

7 tools

Problem. Agents need governed, paged, read-only access to facts without raw SQL.

Exhibit cells, obligations on both prime contracts, the variance register, the knowledge graph and the work register, each through a validated tool.

Beyond CVN-79
Any team that keeps its facts in Unity Catalog.
Today
Generated by the Creator, then edited by hand; golden set of 17 items with independent answers. Planted injection records: 15 of 16 answers correct, none followed the instruction.

One Hub server (mcp-aircarrier-hub)

16 read-only tools

Problem. An AI agent can put a wrong figure in a leadership brief or a financial statement in one sentence.

hub_check_claim routes any candidate figure through policy and the gate, against its own hull's total, and never promotes on its own; hub_challenge_text falsifies text against recorded error classes; hub_tie_out closes totals in exact decimals without a model; the gap tools turn every unknown into an owned request.

Beyond CVN-79
Any office that lets an agent draft numbers: comptrollers, audit liaisons, budget shops.
Today
Deployed as a Databricks App on 2026-11-21 and watched by the probe: known answers right at p50 54 ms. Refuses a VERIFIED tag without a source and page, and a hull it has no total for (R9). An output schema on all 16 tools; 33 server tests; 193 hostile arguments, none leaked. Ask the evidence calls it over MCP.

Probe

every 15 minutes

Problem. When an agent reports a failed connection, nobody can tell whether the server or the connector broke.

Calls each server as a non-human caller through initialize, tools/list and one known-answer check, and logs which step failed.

Beyond CVN-79
Any agency running MCP servers in production, as continuous monitoring evidence for an authority to operate.
Today
413 sweeps, 2026-11-12 to 2026-11-20: 99.90% of 6,193 checks ok; 1,234 of 1,234 known answers right.

Source and README

Front center, agents, skills

6 agents, 3 skills

Problem. Leaders and analysts need the answer, not the tools.

Pages that each answer one question. Ask the evidence is an MCP host: it calls the docs, ops and One Hub servers (34 tools) and names the server behind each step. Six agents (investigator, reader, tie-out, challenger, attributor, briefer) hand work to each other only through the work register; three Genie Code skills.

Beyond CVN-79
Program offices, comptroller staff, auditors.
Today
Live as a Databricks App: one question answered with four tool calls across three MCP servers. Also runs locally from the bundled data with two commands.

Security, by risk

SQL injectionIdentifiers allow-listed and quoted; values bound as parameters; 421 hostile calls, none pasted into SQL
Code injection into generated projectsFree text made inert; eight payloads fuzzed; every generated file compiled with warnings as errors; 403 hostile calls to the Creator, nothing written outside its root
Unwanted writesRead-only tools except one gated label write; Creator writes are dry runs; deploy needs an approval token bound to the reviewed design
Identity and grantsPer-user OAuth through Databricks Apps; tables read as the caller under Unity Catalog; the MCP host sends its token only to a Databricks Apps host at /mcp; no credentials in code
Prompt injectionRetrieved text is data, never instructions; any result holding text aimed at a model carries a source notice; planted records: 15 of 16 answers correct, none followed
ErrorsEvery server returns a failure as isError with its reason and a hint, so a client never counts an error as an answer
