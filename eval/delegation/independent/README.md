# Independent question set (round 5 kit)

Every sealed question so far was written on the builder's side: generated by a seeded script,
or drafted by Genie Code and reviewed by the project owner. An author who did not build the
tools would test them harder. This folder is the kit for that author. It has not been run yet.

## For the author (about an hour)

1. Write ten questions in `questions_template.csv`, one per row, that a financial manager,
   analyst or auditor would ask about CVN-79 or the Ford class. Each needs an answer you can
   point to in a public source, and the page, table or record where it is printed.
   Sources the servers read: the SCN budget justification books (PB2006 to PB2027), the CVN 78
   class SARs and MSARs, GAO and CRS reports, and the USAspending and FPDS records for the two
   prime contracts (N00024-09-C-2116 and N00024-15-C-2114).
2. Mix the kinds: figures from an exhibit, contract obligations, a question that needs two
   sources, and at least two questions with a false premise (the right answer says so).
3. Do not look at the tool list or the server code while writing.
4. Run `python seal.py questions_template.csv` and email the printed SHA-256 to the project
   owner before you send the file. The hash proves the questions did not change after the
   tools saw them.

## For the runner

1. Check the file's SHA-256 against the emailed hash and record both in `SEAL.md`.
2. Write a grader key per question from the author's answer, and test that the author's answer
   passes it and at least one plausible wrong answer fails, as in `round4/human_keys.json`.
3. Run the round 4 runner on the new file (both models, no tools and three repeats with tools)
   and publish every answer and every miss with its cause.

| Column | What to write |
| --- | --- |
| qid | I01 to I10 |
| category | exhibit, obligations, document, multi_source, premise or judgment |
| question | The question as you would ask a colleague |
| answer | The answer, with units |
| source | Document and page, table or record |
| provenance | Your name and office, and the date |
